MusicMan Feature Reference

Raspberry Pi 4B · Flask + Gunicorn · WLED · DMX · WebSocket · Solix C300 · iPad Console

🎤 Walk-Ups
Circles
Kid walk-up cards with photo, name, and custom tagline. Each fires a full entrance sequence.
Roles
Role-based walk-up cards (Chief, Scout, etc.) with their own photo, music, and animation.
Walk-Up Pipeline
Each walk-up fires simultaneously: entrance music starts → projector crossfades to the kid's card → lighting scene switches → animation plays on-screen → stage scene restores when audio ends. Configurable per-entry: music file, SFX, display animation, lighting scene, entrance duration.
Game Entries
Walk-up-style presentation for game contestants — same pipeline, separate library. Callable from macros or Show Flow.
Asset Library
Per-entry images and animations stored on Pi, linkable from the shared display-asset library or uploaded directly.
📺 Projector Display
Slides
Rich full-screen slides: headline, body, background color/image, logo. Templates include Text, QR Code, and Image. Saved library with one-tap push to display.
VS Cards
Split-screen confrontation layout showing two opponents side-by-side with photo, name, letter fallback avatar, and team color.
Images & Animations
Push any uploaded image or video file to the display. Animations play with configurable duration, loop flag, and hold-last-frame option.
Display Navigation
Console controls kiosk browser: navigate to display home, games, or any route. Auto-navigates home before display events if needed.
Standby Screen
Idle state shows a configurable default image. Triggered manually or after certain actions (timer expire, etc.).
Display Clear
Instantly blacks out the projector and resets display state — one tap from the Console.
🔊 Audio Engine
Music Playback
Play any uploaded track with fade-in/out, pause, resume, and per-track volume. Supports MP3, FLAC, OGG, WAV, M4A, AAC.
SFX Engine
Separate audio channel for sound effects — plays over music without interrupting it. Pre-warmed SFX cache for zero-latency climax shots.
Playlist Engine
Play a folder of tracks in order or shuffle. Next/prev controls. Integrates with USB drives for bring-your-own-music.
USB Playback & Import
Browse USB drives, play tracks directly, or import files into the Pi's library. Supports bulk import by folder.
Volume Control
Independent volume sliders for music and SFX. Master audio fade. Audio can be killed instantly from console.
Audio Normalization
Background loudness normalization job for the music library. Status tracking — shows progress and which files have been processed.
⏱ Timers
Countdown Timer
Configurable duration with start/pause/reset. Optional warning sound + warning scene at a set threshold. Expiry sound + end display. Shows on projector with overlay or full-screen mode.
Skit Timer (Presets)
Named timer presets (e.g. "Round 1 — 2 min") stored in Admin and loaded with one tap. Each preset sets duration, warning time, sounds, scenes, and end behavior. Saveable and recallable mid-show.
Stopwatch
Count-up timer for race timing. Start, stop, reset. Record button saves elapsed time as a game score.
Countdown Widget
Separate simple countdown (not the main timer) for quick "3-2-1" style display sequences without touching the main timer state.
💡 Lighting
Scenes
Named lighting presets that set WLED strips, DMX fixtures, and pole flashlights simultaneously. Scenes drag-reorderable in the Console. Callable from macros, walk-ups, timers, and the crowd meter.
WLED Strip Control
Per-segment control: effect, color, brightness, speed. Fires WLED presets on pole nodes or direct HTTP segment overrides. Supports all standard WLED effects (solid, fire, rainbow, strobe, fade, theater, twinkle).
DMX Fixtures
ESP32+MAX485 pole nodes drive DMX fixtures (pinspot, wash, PAR). Per-channel values per scene with master-dimmer scaling. Animated DMX sequences with interpolated frame-to-frame transitions.
Master Dimmer
Global brightness slider scales all active DMX fixture outputs. WLED brightness controlled per-scene.
WLED Tune / Live Edit
Real-time WLED parameter slider for effect speed and intensity — fine-tune the active scene from the Console without going to Admin.
Pole Flashlights
Solix C300 battery-unit flashlights controllable per-scene via BLE: off, low, high, SOS. Scenes specify per-pole mode.
Call & Response Zones
Stage and crowd zones that can be toggled on/off independently — colored LED cues for call-and-response activities.
DMX Animation
Per-scene looping DMX keyframe animations. Frames interpolate smoothly; interval and transition configurable in Admin.
⚡ Macros & Show Flow
Macros
Multi-step sequences executed in parallel or series. Steps can be any combination of: scene, SFX, music, audio fade/stop, display image/animation/slide, walk-up, VS card, viz show/hide, game, timer start/reset, skit timer preset, wait.
Show Flow
Ordered list of macro steps that runs the full show in sequence. Advance, skip, or reset from the Console. Saveable as named templates — load a whole show in one tap.
Show Flow Templates
Store multiple show configurations as named templates. Load any template to replace the active show flow without editing macro definitions.
Kill All
Single button stops all audio, resets crowd state, and returns to idle — emergency override for anything running.
🎮 Games
Prize Wheel
Configurable spin wheel displayed on the projector. Entries are named wedges with individual colors. Spin plays audio and animates to a random stop. Winner is highlighted.
Shell Game
Three-cup find-the-ball game rendered on the display. Themes (cup art, backgrounds) are configurable and swappable. Has its own music and SFX channels.
Scoreboard
Per-game score tracking with add, edit, delete, and display-push. Scores persist between sessions. Displayed on projector in a styled leaderboard overlay.
Saved Game Configs
Each game type can have multiple named configurations (e.g. different wheel entry sets). Saved configs show as tiles in the Console — one tap to go live.
Race Timer Integration
Stopwatch ties into the game score system — stop the watch and record the time as a scored entry with one tap.
Crowd Score Recording
Record the current crowd level (from the Crowd Meter) as a scored entry for crowd-judged game rounds.
📢 Crowd Meter
Level Slider
Manual crowd level 0–100%. Moving the slider drives WLED strip brightness and DMX fixture intensity in real time.
Auto Mode (Mic)
Pole microphones polled every 2 seconds via WLED Sound Reactive firmware. EMA-smoothed signal drives crowd level automatically. One-tap toggle between manual and auto.
Climax
One-tap peak event: fires a configurable Climax macro (strobe, explosion video, SFX, any scene) then automatically runs a Revert macro after a configurable duration. Post-climax lockout blocks crowd lights until the operator re-engages.
DMX Fixture Tracking
Selected DMX fixtures (pinspot, wash, PAR) track crowd level — brightness and color shift across three configurable stops (low / mid / high colors).
WLED Strip Tracking
WLED strips on designated poles track crowd level: brightness and color follow the same low/mid/high gradient. Climb mode adds an animated fill effect.
Video Overlays
Three assignable crowd buttons trigger transparent WebM/MP4 overlays on the display (e.g. "GET LOUD!" banner). Each slot has a name, file, and loop setting.
Preset System
Named crowd meter presets stored in Admin (colors, fixtures, climax macro, duration). Activate a preset from the Console without touching Admin mid-show.
Applause Mode
Dedicated applause up/down controls that pulse crowd lights for audience response cues.
📊 Visualizer
Music Viz
Real-time audio analysis (ffmpeg + FFT) drives animated graphics on the projector display. Styles: Bar, Circle, Radial Bars, Radial Dots, VU Meter.
Crowd Viz
Crowd level rendered as visual feedback on the display (needle + dB bars). Responds to the live crowd meter level in real time.
Viz Presets
Named presets save the full viz configuration: type, colors, speed, sensitivity, center media. Activate from the Console mid-show without going to Admin.
Center Media
Radial viz styles support an optional center image or video (logo, mascot) from the display library, composited over the animation.
🎛️ Stream Deck
USB Stream Deck on the Pi
Hardware Stream Deck connected via USB directly to the Pi, running as a dedicated service. Stays live via WebSocket — buttons light up, dim, and show state changes as the show runs. Auto-reconnects on USB drop.
Show Flow Keys
Each show step gets its own key: numbered, named, active (bright border), done (dimmed + checkmark). Fire any step by pressing it. Overflow to a second page if the show exceeds 12 steps.
Walk-Up & Role Buttons
Circle and role buttons load each kid's or role's actual logo photo onto the key face. Active walk-up glows with a colored border. Up to 13 per page.
Audio Transport
Stop, pause/resume, fade out. Music and SFX volume up/down — key face shows current percentage in real time.
Live Timer Key
Timer key displays MM:SS countdown updating every second. Shows "PAUSED" state in grey, "RESET" when idle. Available on Main and both Show pages simultaneously.
SFX & Macro Pages
Dedicated pages for sound effects (up to 13) and macros (up to 13). One press fires. Color-coded by type.
Display Page
Blackout, standby, and up to 10 display files (images/video) directly pushable from the deck. No Console needed.
Auto-Reconnect
Service reconnects automatically on USB disconnect. Includes a USB reset helper (sudo NOPASSWD) to recover HID lock-ups without rebooting the Pi. Retries every 3s; resets every 5th failed attempt.
🌐 Networking & System
Access Point
Pi hosts its own WiFi network (MusicMan / BrokenArrow). All connected devices appear in the Console's client list. AP restartable without rebooting.
WiFi Client
Scan, connect to, and forget WiFi networks from the Admin panel. Saved networks persist across reboots.
Health Monitor
Real-time status dots for: musicman service, display page, audio, iPad/remote connected, pole nodes, WLED devices.
Battery Monitor
BLE connection to Solix C300 units per pole. Reads charge %, AC/DC state. Controls AC outlet, DC outlet, and flashlight mode per unit.
System Controls
Restart service, restart kiosk browser, or full system shutdown — all from the Console without SSH.
OTA File Update
Upload a replacement musicman.py from the Admin panel; service restarts automatically with the new code.
DHCP Sync
One-tap sync to push static DHCP leases for pole nodes into dnsmasq config — keeps pole addresses stable without manual edits.
WLED Proxy
Pi proxies WLED configuration pages for each pole node — access any pole's WLED UI through musicman.local without leaving the browser.
⚙️ Admin Configuration
Walk-Ups — Circles & Roles
Full CRUD editor: name, tagline, photo upload, entrance music, animation, display duration, lighting scene. Photo can come from upload or shared library.
Slides Builder
Visual slide editor with live preview. Templates: Text, QR Code (auto-generated), Image. Background and logo configurable. Saved library with one-tap push or macro inclusion.
VS Cards Editor
Two-sided card editor with photo upload or library link, name, and color per side. Fire directly or include in macros.
Scene Editor
Build lighting scenes: configure per-device WLED zones (effect, color, brightness, speed), DMX fixture channels per pole node, WLED preset number, pole flashlight mode, and optional DMX animation keyframes.
Macro Builder
Step-by-step macro editor. Add, reorder, and configure each action type. Parallel vs sequential execution per step.
Lighting Hardware
Register WLED devices, pole nodes (ESP32+MAX485), fixture types, and fixture definitions. Test DMX channels live. Sync DHCP. View WLED presets per node.
Audio Library
Browse, rename, delete, and normalize music and SFX files. Upload new files or import from USB. Link files to assets without duplicating storage.
Timer Presets
Create and manage named skit timer presets with full configuration: duration, warning threshold, sounds, scenes, end display behavior.
Crowd Meter Settings
Configure WLED crowd lights, DMX fixture tracking, color stops (low/mid/high), climb mode, strip parameters, video overlay slots, climax macro, revert macro, and climax duration — all saveable as named presets.
Viz Preset Editor
Build and save music and crowd viz presets: style, colors, speed, sensitivity, center media. Preview-ready for both music and crowd scenes.
