# MusicMan

> Started as a fart machine for Adventure Guides campfire. Became something much bigger.

MusicMan is a campfire show production system that runs on a Raspberry Pi. It gives you walk-up music and animations for each circle, a show flow runbook, a soundboard, lighting control, games, timers, and a full admin panel — all controlled from any phone or tablet on the network. No internet required.

Built by a dad, for dads.

## What It Does

- **Circles & Roles** — Each circle and role gets its own walk-up music, intro clip, loop animation, and lighting scene. Tap to trigger.
- **Show Flow** — Build a rundown of your whole campfire. Step through it live with one button.
- **SFX Soundboard** — Air horn, sad trombone, Ric Flair, whatever you need. Instantly.
- **Music** — Playlist playback with volume control, fade, and shuffle.
- **Lighting** — Control WLED nodes and DMX fixtures by scene. Scenes trigger automatically during walk-ups.
- **Timers** — Countdown timers with warning sounds, end sounds, and display output. Skit timer, 2-minute timer, whatever you save.
- **Games** — Prize Wheel, Musical Chairs, Trivia, Shell Game, Head to Head, Timed Competition (races/challenges with remote stopwatch control), Countdown Timer, and more — built-in guessing/competition games with custom images, sounds, and music.
- **Display** — Drive an HDMI screen with logos, animations, timer display, and slides. Optionally pulls photos from a group BAND album for a full-screen slideshow with a QR code inviting attendees to add their own.
- **Battery Monitor** — Track your Solix/EcoFlow power station in real time, per pole.
- **Stream Deck** — Optional physical control surface: fire scenes, macros, music, slides, and games directly from a USB Stream Deck, mirroring the console.
- **Admin Panel** — Set everything up from a browser. Upload assets, configure circles, build macros, manage WLED nodes.

## Hardware

**Required**
- Raspberry Pi 4B or 5
- MicroSD card (32GB+)
- Powered speaker (aux or USB audio)

**Optional**
- HDMI display (for audience-facing visuals)
- WLED lighting nodes (ESP32-based, for walk-up lighting)
- DMX poles (ESP32 + MAX485, for pinspots, wash lights, and PAR fixtures)
- Solix or EcoFlow battery for portable power (one per pole, plus a separate USB battery bank for the Pi)
- USB Stream Deck (physical control surface)
- Physical power button + WS2812B status LED on the Pi (startup/shutdown feedback without a monitor)

See [`WIRING_GUIDE.md`](WIRING_GUIDE.md) for full physical wiring — Pi, pole nodes, DMX chain, and power distribution.

## How It Works

MusicMan runs as a web server on your Pi. When it boots, the Pi creates its own WiFi access point. Phones, tablets, and laptops connect to that network and open the MusicMan console in a browser — no app install, no internet.

The person running the show controls everything from the console. The audience sees the display (if you have one connected). Walk-up sequences, lighting, and audio all fire automatically based on what you trigger.

## Project Structure

```
musicman.py          # Main application (Flask + WebSocket)
streamdeck.py         # USB Stream Deck driver (optional hardware)

config.starter.yaml  # Starter config — copy to config.yaml and edit
install.yaml         # Machine settings — generated by setup script

assets/              # Your media — not in repo, lives on the device
  music/   circles/  roles/  sfx/  display/  shell_game/
```
