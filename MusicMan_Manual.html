PART 1

What Is This?

System Overview

MusicMan is a show controller that runs on a Raspberry Pi. It lets one person — from a phone, tablet, or laptop — control music, lighting, sound effects, timers, and the HDMI display during a live campfire show. Everyone else sees a polished production; the operator sees a simple web console.

There is no software to install on the device you use to control it. You just open a web browser and go to the Pi's address.

What It Controls

SystemWhat MusicMan does
MusicPlays walk-up music for each circle, music from a library, and countdown background tracks
Sound EffectsTriggers one-shot SFX from a library of .wav and .mp3 files
LightingSends scene commands to WLED LED controllers over the network
HDMI DisplayShows countdown timers, leaderboards, images, and animations on a projector or TV
TimersSkit timer (with HDMI warning), games countdown timer, stopwatch
Show FlowA scripted sequence of steps that fire macros automatically, in order

Hardware You Need

  • Raspberry Pi (any model with Wi-Fi, Pi 3B+ or newer recommended)
  • Power supply for the Pi
  • Speakers connected to the audio output jack on the box
  • HDMI display, TV, or projector connected to the Pi's HDMI port
  • USB drive with your music, SFX, and image files
  • Wi-Fi network that both the Pi and your control device share
  • Control device — any phone, tablet, or laptop with a browser
  • WLED lighting controllers (optional — lighting scenes require these)
PART 2

Setup

Physical Connections

  1. Connect your speakers to the audio output jack on the box.
  2. Connect the HDMI display or projector to the Pi's HDMI port.
  3. Plug in your USB drive (with music/SFX files) into another USB port.
  4. Connect the Pi to power. Give it about 30–60 seconds to fully boot.
  5. Make sure the Pi and your control device are on the same Wi-Fi network.
Finding the Pi's IP address
If you don't know the Pi's IP address, check your router's connected device list, or look for a device named musicmanpi (or similar). The address typically looks like 192.168.x.x.

The HDMI Display

This is automatic. You don't need to do anything. When the box powers on, it waits for the HDMI display to be connected and for the show software to finish starting, then launches the audience display fullscreen on its own. Just plug in the HDMI cable before you power on the box and it takes care of the rest.

If the display isn't showing
Make sure the HDMI cable was plugged in before powering on the box — the Pi needs to detect the display at boot. If the box is already on and the screen is blank, give it 30 seconds after connecting the cable. If it still doesn't appear, log into the admin panel and use ⚙ System → ↗ OPEN DISPLAY PAGE to confirm the service is running, or try unplugging and replugging the HDMI cable.

Using a separate display device (laptop, second computer):
If you want a different device to drive the projector or TV instead of the box's HDMI output, open a browser on that device and navigate to:

http://musicman.local/display

Press F11 to go fullscreen. It will show exactly the same content as the HDMI output, synchronized live.

Connecting from Your Control Device

On any phone, tablet, or laptop on the same Wi-Fi, open a browser and go to:

http://<Pi-IP-address>

This is the operator console. Bookmark it.

For admin configuration, go to:

http://<Pi-IP-address>/admin

Tip — multiple devices
You can have the console open on multiple devices at once. Changes on one appear on all of them instantly. Useful if you want a helper watching a tablet while you run the show from a phone.

Accessing Files from Your Computer

You can connect your Mac or Windows PC directly to the Pi's file system and drag files in just like any other folder — no USB drives, no terminal commands. There are two ways to do it. Option A (SFTP) works immediately with free software. Option B (Network Folder/Samba) requires a one-time setup on the Pi but feels more like a normal folder after that.

Option A — SFTP with Cyberduck or WinSCP (easiest, works immediately)

SFTP is a secure file transfer protocol that uses the Pi's existing SSH access — no extra setup on the Pi needed.

Mac: Download Cyberduck (free, cyberduck.io). Open it, click Open Connection, choose SFTP, and enter:

FieldValue
Servermusicman.local (or the Pi's IP address)
Usernamepi
PasswordThe Pi's login password (default: raspberry)
Port22

Once connected, navigate to /home/pi/musicman/assets/ and drag files in.

Windows: Download WinSCP (free, winscp.net). Create a new site, choose SFTP, and use the same server/username/password as above. The file manager shows the Pi's folders on the right and your PC on the left — drag files between them.

Tip — you can bookmark it
Both Cyberduck and WinSCP let you save the connection as a bookmark. Set it up once and it's a two-click connection from then on.

Option B — Map as a Network Folder

The box is already configured as a network file server. No setup required — just connect from your computer using the credentials below.

FieldValue
Addresssmb://musicman.local (Mac)  /  \\musicman (Windows)
Usernamepi
PasswordBrokenArrow
Share namemusicman

Connecting on a Mac:

  1. Open Finder. In the menu bar, click Go → Connect to Server…
  2. Type: smb://musicman.local and click Connect
  3. When prompted, enter username pi and the Samba password you set above.
  4. Select the musicman share. It mounts as a drive on your Desktop and in Finder's sidebar.
  5. Navigate to assets/sfx/, assets/music/, etc. and drag files in directly.
Mac tip — reconnect automatically
After connecting once, you can add the share to your Login Items so it mounts automatically when you open your Mac. In System Settings → General → Login Items, click + and browse to the mounted drive.

Connecting on Windows:

  1. Open File Explorer. Click in the address bar at the top.
  2. Type: \\musicman and press Enter. (If that doesn't work, try \\<Pi-IP-address> instead.)
  3. Enter username pi and the Samba password when prompted.
  4. You'll see the musicman folder. Open it and navigate to assets\sfx\, assets\music\, etc.
  5. To make it permanent: right-click This PC in File Explorer, choose Map Network Drive, pick a drive letter, and enter \\musicman\musicman as the folder path. Check Reconnect at sign-in.
After adding files via network folder
The app picks up new files in the SFX and Music folders automatically. For images and videos added to assets/display/, refresh the Admin → Display page to see them appear. After adding walk-up assets directly to circle/role folders, you may need to refresh the Admin → Circles or Roles page.

USB Drive File Layout

The Pi reads media from a USB drive. The drive can contain any folder structure — MusicMan scans the whole drive — but the app's own local asset folders on the Pi itself use this structure:

FolderContents
assets/music/Walk-up and background music tracks (.mp3, .wav)
assets/sfx/Sound effects (.wav, .mp3)
assets/circles/Circle-specific walk-up audio
assets/roles/Role-specific walk-up audio (Chief, etc.)
assets/display/Images shown on the HDMI display

Music on the USB drive (any subfolder) also appears in the Music tab of the console, so you can play anything on the drive without copying it to the Pi first.

Swapping USB Drives

If you get a new USB drive and want to move everything over:

  1. Copy all folders and files from the old drive to the new drive, keeping the same folder structure.
  2. Eject the old drive from the Pi, plug in the new one.
  3. The system automatically detects it. No configuration change needed.
Tip — drive label doesn't matter
The app finds USB drives by scanning the mount point, not by name. So the new drive can have any volume label.
PART 3

Admin Configuration

Everything in this section is done once (or updated before a show) from the Admin panel at http://<Pi-IP>/admin. Changes save immediately — there's no "Submit" button on most screens.

Step 0: Load Your Media Files First

Before you configure walk-ups, macros, or timers, you need to get your audio, image, and video files onto the system. Everything else references these files by name — if a file isn't loaded yet, it won't appear in any dropdown.

All file loading is done from the Admin panel. Open a browser and go to http://<Pi-IP>/admin.

Sound Effects (SFX)

SFX are one-shot sounds fired from the SFX tab in the console: air horns, drum hits, crowd noise, etc.

Supported formats: MP3, WAV, FLAC, OGG, M4A, AAC, OPUS

  1. In Admin, click ♪ Audio in the left sidebar.
  2. Under the SFX section, click the dashed upload zone (or drag files onto it).
  3. Select one or more audio files. They upload immediately and appear in the list below.
  4. Use the ▶ button next to any file to preview it through the Pi's speakers before a show.
  5. Use the pencil icon to rename a file, or the trash icon to delete it.
Tip — naming SFX
The filename is what appears in every dropdown. Name files clearly: AirHorn.mp3, DrumRoll.wav, Crowd_Cheer.mp3. No spaces in filenames is safer — use underscores instead.

Background Music (Music Library)

The music library is the pool of tracks used for walk-up music, skit timer background music, and manual playback from the Music tab. These are longer pieces — songs, ambient tracks, etc.

Supported formats: MP3, WAV, FLAC, OGG, M4A, AAC, OPUS

  1. In Admin, click ♪ Audio in the left sidebar.
  2. Under the Music section (below SFX), click the dashed upload zone or drag files onto it.
  3. Select one or more tracks. Multiple files can be uploaded at once.
  4. The track name in dropdowns is the filename (minus extension). Rename files to be descriptive.
Tip — USB drive as music source
Any audio files on the USB drive (in any folder) automatically appear in the console's Music tab without uploading anything. This is useful for large libraries you don't want to copy onto the Pi. However, files must be on the USB drive and the drive must be plugged in — they won't appear in Admin dropdowns for walk-up music. Upload to the Music library for those.

Display Images

Display images are shown fullscreen on the HDMI screen — circle logos, slide backgrounds, photo backdrops, title cards, etc. They can be triggered from the Display tab in the console, from macros, or automatically during a walk-up.

Supported formats: JPG, PNG, GIF (animated GIFs work), WebP

Recommended size: 1920 × 1080 pixels (16:9, matching a standard HD projector or TV). Images are scaled to fit the screen, but starting at the right size looks sharpest.

  1. In Admin, click 🖼 Display in the left sidebar.
  2. Click the dashed upload zone at the top, or drag image files onto it.
  3. Uploaded images appear as thumbnails. Click any thumbnail in the console's Display tab to show it on HDMI.
  4. To delete an image, hover the thumbnail in the admin Display section and click the trash icon.

Display Video

Video files can also be displayed fullscreen on the HDMI screen. Use them for animated backgrounds, intro sequences, countdown animations, or anything you want the audience to see.

Supported formats: MP4 (H.264), WebM, MOV, OGV

Best bet: MP4 with H.264 encoding. It plays reliably on the Pi and works in any browser.

Recommended size: 1920 × 1080 or smaller. Very large video files (over 500 MB) may stutter on the Pi — compress them if needed.

  1. In Admin, click 🖼 Display.
  2. Upload video files the same way as images — same upload zone accepts both.
  3. Videos appear in the Display tab alongside images. Tapping a video file plays it fullscreen on the HDMI display (it loops until you clear the display or show something else).
Large files take time
Uploading large audio or video files over Wi-Fi may take a minute. The browser tab will show progress. Don't close the tab or refresh until it finishes. If a file is very large (>200 MB), it's faster to copy it directly onto the Pi via a USB drive or SSH — see the next tip.
Tip — copy files directly onto the Pi via SSH
If you're comfortable with a terminal, you can copy files directly to the Pi over the network without using the browser uploader. From a Mac or Linux computer on the same Wi-Fi:

scp myfile.mp3 pi@<Pi-IP>:/home/pi/musicman/assets/sfx/

Replace sfx with music or display as appropriate. The password is the Pi's normal login password (default: raspberry). After copying, tap ↺ SCAN or refresh the admin page to see the new files.

Walk-Up Assets (per Circle or Role)

Each circle and role has its own set of assets: a walk-up music track, a logo image, and optionally two video clips that play on the HDMI screen during the walk-up.

AssetWhat it doesFormat
Walk-up MusicPlays when you fire their walk-up from the consoleAudio (any)
Logo ImageShown fullscreen on HDMI while music playsImage (PNG recommended)
Intro AnimationVideo that plays once before the music starts — a dramatic revealMP4, WebM
Main AnimationVideo that plays on loop while the music playsMP4, WebM

You don't need all four — Music and Logo are the most common. Intro and Main animations are optional extras.

  1. In Admin, click ⬡ Circles (or ★ Roles).
  2. Select a circle from the list.
  3. You'll see an asset slot for each type. Click any slot to open a file picker for that asset type.
  4. Alternatively, for Walk-up Music: click 📚 PICK FROM LIBRARY to choose a file you already uploaded to the Music library instead of uploading a new one.
  5. A green checkmark on the slot means the file is loaded. Use the ▶ PREVIEW button to hear or see the asset before the show.
  6. Use ✕ CLEAR to remove an asset from a slot without deleting the file.
Tip — walk-up music vs. library music
Walk-up music uploaded directly to a circle's slot is stored in that circle's own folder (assets/circles/MightyCreek/walkup.mp3). Picking from the library points to the shared music library instead. Either works — the "pick from library" option is useful when multiple circles share the same walk-up track.

Circles (Walk-Ups)

A Circle entry stores everything needed to announce that circle: their music, their logo or animation on the HDMI screen, how long the music plays, and which lighting scene fires. When you tap a circle button in the console, all of this happens automatically.

Creating a circle

  1. In Admin, click ⬡ Circles in the sidebar.
  2. Click + NEW CIRCLE. Type the circle's name (e.g., "Mighty Creek") and click OK.
  3. The circle appears in the list on the left. Click it to open the editor on the right.
  4. Fill in the fields (see table below), then click ✓ SAVE CIRCLE.

Roles (Walk-Ups)

Roles work exactly like circles, but for individual positions — Expedition Navigator, Firestarter, Story Teller, Chief, Dad of the Year, etc. They have their own tab in the console (ROLES) and the same full editor as circles.

  1. In Admin, click ★ Roles in the sidebar.
  2. Click + NEW ROLE. Enter the role's name and click OK.
  3. Click the role in the list to open its editor. All the same fields as circles apply (music, logo, clips, timing, lighting).
  4. Click ✓ SAVE ROLE.

Role buttons appear in the console's ROLES tab. Tapping one plays their music and fires their lighting scene, just like a circle walk-up.

Lighting Scenes

A Scene is a named lighting state. Scenes are sent to WLED LED controllers over Wi-Fi. You define the scene here, and MusicMan sends the command when it's triggered (by a macro, a walk-up, or a console button).

  1. In Admin, click ✦ Lighting Scenes.
  2. Click + NEW SCENE. A new scene card appears in the list.
  3. Click the card to open the editor. Fill in:
FieldWhat it does
NameLabel shown on the console scene button (e.g., "Campfire", "Blackout")
IDInternal identifier — lowercase, no spaces (e.g., campfire). Auto-filled from the name.
IconEmoji shown on the scene button (e.g., 🔥, 💡, ⚫)
DescriptionShort note for the operator — not shown to the audience
ZonesOne row per WLED controller. Each row has: Zone ID (the WLED device's name or IP), Effect (the WLED preset number to activate), and Brightness (0–100).
  1. To add a zone, click + ADD ZONE. Enter the Zone ID (must match how you've set up your WLED device), the effect number, and brightness.
  2. Click SAVE SCENE.
No lighting? No problem.
If you're not using WLED lighting, just ignore the Scenes section entirely. Scenes assigned to walk-ups or macros will silently do nothing if no WLED devices are reachable.

Macros

A Macro is an ordered list of steps that execute one after another when triggered. A single tap on a show flow item can play music, set lights, show an image, load a timer preset, and more — all from one macro.

Creating a macro

  1. In Admin, click ⚡ Macros.
  2. Click + NEW MACRO. Give it a name (e.g., "Circle 1 Intro"), an optional ID, and an optional description.
  3. Optionally upload a Display Image — this image shows fullscreen on the HDMI the moment the macro fires (before any steps run).
  4. Under STEPS, use the dropdown to pick a step type and click + ADD STEP.
  5. Configure each step's fields. Drag steps up/down to reorder.
  6. Click ✓ SAVE MACRO.
  7. To test without going through the show flow, click ▶ TEST.

Tip — steps run immediately, one after another
Steps don't wait for audio to finish — they fire in rapid sequence unless you add a Wait step. If you want music to play for 10 seconds before the lights change, add a Wait (10 sec) step between them. The one exception is Walk-Up steps, which manage their own timing internally.
Tip — duplicating macros
Click ⧉ DUPLICATE on any macro to copy it as a starting point for a new one. Useful when several show items have similar structure (play music → set scene → load timer).

Show Flow

The Show Flow is the master rundown for the show — an ordered list of named items, each linked to a macro. During the show, you tap items one by one in the console's SHOW tab, and each one fires its macro automatically.

Building the show flow

  1. In Admin, click ▶ Show Flow.
  2. Click + ADD STEP.
  3. In the editor panel on the right, fill in:
FieldWhat it does
MacroThe macro that fires when this item is tapped in the console
Display NameThe label shown on the button in the console (e.g., "Opening", "Circle 1 – Mighty Creek", "Games")
NotesReminder text shown below the button in the console — visible to the operator but not the audience. Use this to cue yourself: "Henry walks up, intro music plays, lights go warm."
ColorButton color in the console — purely visual, helps you scan the list quickly
  1. Click ADD TO SHOW (or the equivalent save button in the panel).
  2. Repeat for each show segment. Drag items in the left list to reorder them.
  3. Click SAVE SHOW FLOW when done. This is the one place you need to explicitly save.
Always save the Show Flow
Unlike most admin screens, the Show Flow requires you to click SAVE SHOW FLOW at the bottom of the left panel before your order is persisted. If you reorder items and close the browser without saving, the order reverts.

Skit Timer

The skit timer is the countdown shown in the left panel of the console during skits. Configure it in Admin → ⏱ Timer.

Timer settings

SettingWhat it does
DurationHow long the timer runs, in seconds (e.g., 180 = 3 minutes)
Warning AtSeconds remaining when the warning triggers on the HDMI screen (default: 15). A flashing countdown appears on screen even if "Show on Screen" is off.
Start SoundMusic track or SFX that plays the moment the timer starts. Pick from the music or SFX library.
Start Sound — Start AtJump into the track at this many seconds (0 = from the beginning). Useful to skip a long intro.
Start Sound — DurationHow long to play the sound, in seconds. Set to 0 to play for the full timer duration.
Start Sound — FadeHow the sound ends: 0 = play once and stop. Any positive number = loop continuously and fade out that many seconds before the end sound plays.
Warning SoundSFX that plays at the warning point (e.g., a buzzer or drum roll)
Warning SceneLighting scene to activate at the warning point
End SoundSFX that plays when the timer hits zero
End SceneLighting scene to activate when the timer expires
Music that loops and fades — the key rule
Fade = 0: plays the sound file once from beginning to end (or to the Duration limit), then stops.
Fade > 0: loops the sound continuously, then fades it out that many seconds before zero. Use this for background music you want to fill the whole skit. Example: Duration = 120, Start Sound Fade = 5 → music loops for 115 seconds, then fades over 5 seconds as the end sound fires.

Saving and loading timer presets

A Timer Preset saves all the current timer settings under a name. Presets can be loaded by a macro step (Load Timer Preset), so the timer is always correctly configured when a show segment starts.

  1. Configure all timer fields the way you want them for a particular segment.
  2. Scroll down to Timer Presets at the bottom of the Timer page.
  3. Check the Will save: summary line — it shows exactly what will be saved.
  4. Type a name in the preset field (e.g., "3 Min Skit", "2 Min Game Intro").
  5. Click SAVE AS PRESET.
  6. To use a preset in a show: create a macro with a Load Timer Preset step and pick your preset name.
  7. To delete a preset: click the trash icon next to it in the presets list.
The preset saves the form, not disk
The preset captures whatever is in the timer form fields at that moment — not necessarily what was last saved. Always glance at the Will save: summary before clicking.

Live Slides

The 📋 Slides tab lets you build and push a custom text slide to the projector without leaving the admin panel — useful for setting up announcements or next-camp info before the show. The same slide builder is also available in the console's DISPLAY tab for on-the-fly use during a show.

Slides appear as a full-screen overlay on the HDMI display and stay up until you push a new one, clear it, or fire a Clear Slide macro step.

Templates

TemplateBest forFields
Big TitleSingle bold announcement — event name, countdown calloutHeadline, optional subtitle
BulletinSchedule or short list — left-justified, line by lineHeader, then lines (one per line)
Next EventUpcoming camp announcement — left-justified layoutLabel (e.g. "NEXT CAMP"), event name, date/location
SpotlightHighlight an individual or circle with a logo imageImage (from display library), title, optional subtitle

Accent colors

Each slide has a colored accent — the stripe, underline, or border that gives it personality. Choose from: Amber (default), Blue, Green, White, or Red.

Using the Slides tab

  1. In Admin, click 📋 Slides in the sidebar.
  2. Click a template button (BIG TITLE, BULLETIN, etc.) to select it.
  3. Fill in the fields that appear below the template row.
  4. Choose an accent color using the colored circles.
  5. Click ▶ SEND TO DISPLAY. The slide appears on the projector immediately.
  6. To remove the slide, click ✕ CLEAR.
Tip — slides survive reconnects
If a browser refreshes or the display page reconnects, the current slide is restored automatically. You don't have to re-send it.
Tip — Bulletin lines
For the Bulletin template, type each line in the text area with a line break between them. Example:

Midnight Meat 10:00 PM
Polar Plunge 11:30 PM
Lights Out 12:00 AM

Slides in macros

Any slide can be baked into a macro using the 📋 Custom Slide step type. When the macro fires, the slide appears automatically — no manual action needed. Pair it with a ✕ Clear Slide step at the end of the segment to remove it.

CPU / Memory / Disk / UptimeLive Pi health stats. Disk full is the most common problem — check here if things stop working.
🔈 RESET AUDIORestarts the audio system without rebooting the Pi. Try this if audio stops working unexpectedly.
⚠ RESTART SERVICERestarts the MusicMan software. Connected browsers will reconnect automatically within a few seconds. Use this after any config file edits done over SSH.
🔌 SHUTDOWN PISafely shuts down the Raspberry Pi. Wait for the activity light to stop blinking before unplugging power.
Always use Shutdown before unplugging
Pulling power while the Pi is running can corrupt the memory card. Click 🔌 SHUTDOWN PI and wait ~10 seconds for the green activity light to go dark before removing power.

Running the Show Flow

The Show Flow is the core of the show. Each item is a button in the SHOW tab.

  1. Open the SHOW tab.
  2. Tap the first show item. Its macro fires immediately — music plays, lights change, timer is configured, etc.
  3. When ready to move on, tap the next show item.
  4. The active item is highlighted. Previous items are dimmed.
Tip — macros run instantly
Tapping a show flow item fires the macro right away — there's no "are you sure?" prompt. Tap deliberately.

Kill All
KILL ALL is the big red emergency button. Use it if something goes badly wrong. It stops all audio, resets the skit timer, and clears the display. It does not reset the show flow position.

Walk-Up Music

Walk-ups play a customized intro track for each circle or role.

  1. Go to the WALKUPS tab.
  2. Tap the circle's button. The walk-up track starts, and their lighting scene fires.
  3. The track plays through automatically. To stop it early, use FADE & END or STOP.
Walk-up during a show flow item
Walk-ups can be triggered at any time — they work independently of the show flow. Walk-up music replaces whatever is currently playing.

Playing Music from the Library

  1. Go to the MUSIC tab.
  2. Browse or search for a track.
  3. Tap it to play. It starts immediately.
  4. Use the transport controls to pause, fade, or stop.

Sound Effects

  1. Go to the SFX tab.
  2. Tap any sound effect button to trigger it.
  3. SFX play on a separate channel — they don't interrupt music.
  4. Adjust the SFX volume with the bottom volume slider in the left panel.

Lighting Controls

Lighting scenes appear as buttons in the left panel under Lighting Scenes. The active scene is highlighted.

  • Tap any scene button to activate it immediately.
  • Use the brightness slider to dim or brighten all lights.
  • Scenes can also be triggered automatically by macros and walk-ups.

The Skit Timer

The skit timer lives in the left panel. Its label shows the name of whatever timer preset is currently loaded (or "SKIT TIMER" if none).

ControlWhat it does
▶ STARTStarts the countdown. Start sound plays if configured.
⏸ PAUSEPauses the countdown (and fades start sound if looping)
↺ RESETResets to full duration. Stops start sound. Clears timer from HDMI.
SHOW ON SCREENWhen checked, the timer appears on the HDMI display from the moment it starts. When unchecked, it only appears on HDMI at the 15-second warning.
The 15-second warning
Regardless of the SHOW ON SCREEN setting, a large countdown always appears on the HDMI display when 15 seconds remain. This is intentional — it's visible to the audience while the full timer runs silently for the operator.

When the Games countdown is running, the timer panel mirrors its countdown and the label changes to GAMES TIMER. It reverts when the countdown stops.

Games Tab

Games Countdown Timer

  1. Go to the GAMES tab.
  2. Set the duration (minutes and seconds) and click SET.
  3. Configure start and end sounds as needed.
  4. Click ▶ START to begin. The left panel mirrors the countdown.
  5. Click ⏸ PAUSE to pause, ↺ RESET to reset.

Stopwatch

The stopwatch is below the countdown timer. Use it to time individual game runs. Hit ▶ START to start, ■ STOP to stop. The elapsed time is ready to record.

Leaderboard

  1. Create a game with + NEW.
  2. After each run, enter the participant's name and click ⏱ RECORD to save the stopwatch time.
  3. Click ▲ FASTEST FIRST / ▼ LONGEST FIRST to toggle sort order. The HDMI display updates automatically.
  4. Click 📺 SHOW ON SCREEN to display the leaderboard on the HDMI.
  5. Click ✕ CLEAR to clear times for the current game.

Live Slide Builder

The DISPLAY tab includes a slide builder at the top for pushing custom text slides to the projector on the fly — no admin panel needed. Use it for last-minute announcements, schedule changes, or anything that needs to go up quickly.

  1. Go to the DISPLAY tab.
  2. Under LIVE SLIDE, tap a template button: BIG TITLE, BULLETIN, NEXT EVENT, SPOTLIGHT, or QR CODE.
  3. Fill in the fields that appear (headline, body text, date, URL, etc.).
  4. Pick an accent color using the colored circles.
  5. Tap ▶ SEND TO DISPLAY. The slide goes live on the projector immediately.
  6. Tap ✕ CLEAR to remove it.
Slides layer over everything
A custom slide appears on top of any image or animation already showing. Clearing the slide reveals whatever was underneath. CLEAR DISPLAY (transport bar) removes everything — slides included.

USB Playlist Tab

The USB tab lets you browse and play music folders directly from a USB drive, without needing to configure anything in advance. Great for pre-show or post-show background music.

  1. Plug a USB drive into the Pi.
  2. Go to the USB tab and tap ↺ SCAN. The tab lists all folders found on the drive.
  3. Tap any folder to start playing all tracks in it as a shuffled playlist. The track name appears in Now Playing.
  4. Use ⏭ NEXT TRACK to skip to the next song.
  5. Tap 🔀 SHUFFLE: ON/OFF to toggle shuffle before selecting a folder.
Tip — no setup required
The USB tab reads whatever is on the drive at the time you tap SCAN. You can swap drives or add folders without touching any configuration — just plug it in, scan, and play.
PART 5

Quick Reference

Pre-Show Checklist

  • Pi is powered on and fully booted (~60 seconds after power-up)
  • USB drive is plugged in
  • Speakers are connected and working — test with any SFX
  • HDMI display is connected, Chromium is open and showing /display in fullscreen
  • Your control device is on the same Wi-Fi and the console loads at the Pi's IP
  • Show Flow is in the correct order (check Admin → Show)
  • Timer presets are correct — fire a test macro and confirm the timer label updates and the duration is right
  • Volume levels are set. Music slider is at your starting level; SFX slider is set.
  • Lighting scenes are working — tap one and confirm the lights respond

Common Workflows

Announcing a Circle

SHOW TAB → TAP CIRCLE'S SHOW ITEM → WALKUPS TAB → TAP CIRCLE BUTTON

Running a Skit with Timer

FIRE SKIT MACRO → TIMER LABEL UPDATES → PRESS START → 15s WARNING ON HDMI

Running a Game

GAMES TAB → SET DURATION → START → STOPWATCH FOR TIMES → RECORD TIMES → SHOW ON SCREEN

Smooth Track Ending

FADE & END → MUSIC FADES OUT

Use FADE & END instead of STOP whenever possible — it sounds much better than a hard cut.

Troubleshooting

ProblemFix
Console won't load in browser Check that your device is on the same Wi-Fi as the Pi. Verify the Pi is powered on and fully booted. Try the IP address directly in your browser.
No audio from speakers Check the Music volume slider isn't at 0. Try playing an SFX — if that works but music doesn't, the music file may be missing or incorrectly named. If nothing plays at all, check speaker connections to the Audio HAT.
HDMI display shows nothing Make sure the display browser is open at /display and is fullscreen. Try refreshing that browser window. Click CLEAR DISPLAY then show something new.
Timer label still says "SKIT TIMER" after firing a macro The macro's Load Timer Preset step may point to a preset that doesn't exist. Check Admin → Macros and verify the preset name matches exactly what's in Admin → Timer presets.
Walk-up music not playing Check that the audio file assigned to that circle still exists in the music folder. Go to Admin → Walkups and re-select the track.
Start sound keeps playing after timer ends This should not happen with current software. If it does, use KILL ALL to stop everything, then reload the page (Cmd/Ctrl + Shift + R).
Something is badly wrong Press KILL ALL. This stops all audio, resets the timer, and clears the display. It's safe to press at any time.
Changes in Admin aren't taking effect Hard-refresh the admin page (Cmd/Ctrl + Shift + R on Mac, Ctrl + Shift + R on Windows/Android).
The Golden Rule
When in doubt: KILL ALL, then reload. The show flow remembers where you were, so you can pick back up without losing your place.
