Overview

How It Works

Music Man runs on a Raspberry Pi that acts as an offline Wi-Fi access point. The Pi hosts this admin panel, an operator console, and drives the projector display, PA audio, and pole lighting — all from one box. No internet required at the event.

There are two interfaces:

Admin Panel /admin

Where you pre-build everything before the show: circles, VS cards, macros, the show rundown. This is the page you're reading help for now.

Operator Console /

The live show controller you use at the event — one button per show step. Fires macros, walk-ups, and displays. Designed for a Stream Deck or tablet.

Overview

Big Picture

The mental model: you configure reusable elements here in Admin, then call them from Show Flow or Macros at showtime.

  • A Circle is a family walk-up package: name, color, logo, music, animation, lighting.
  • A Macro is a multi-step sequence: play audio, set lighting, fire a VS card, etc.
  • A Show Flow is the ordered list of macros (and VS cards / games) for one show.
  • At showtime, the Operator console has one button per show flow step — tap to fire.
  • The display (projector) updates automatically when a walk-up, VS card, or slide is fired.
Walk-Ups

Circles

Each participating family gets a Circle. When their name is called, Music Man fires their walk-up: music starts, the display shows their logo, and the lights flash their color.

Fields

Name & Color

The family name (shown on display) and their accent color (drives the light flash and display highlight).

Logo

Image shown on the projector during their walk-up. PNG with transparency works best.

Walk-Up Music

Audio track that plays when they're called. Use START to trim the intro, DURATION for how long it plays, FADE for the fade-out length.

Intro Clip / Loop Clip

Optional videos. Intro plays once, then Loop repeats until music fades. Leave Loop empty to hold on the last frame of Intro.

Walk-Up Scene

Lighting scene that fires the moment they step up. Leave blank for the default color flash.

After-Fade Scene

Lighting scene that activates after the music fades out. Typically a warm ambient (e.g., Campfire).

Tip: Music files can be picked from the library (already uploaded) or from a connected USB stick. No need to re-upload if a track is already in your library.
Walk-Ups

Roles

Same walk-up pipeline as Circles, but for named staff positions — Chief, Photographer, Ceremony Leader, etc. Roles are stored separately so they don't clutter the family list.

Everything is identical to Circles: name, color, logo, walk-up music, clips, timing, lighting.

Screen

Slides

Pre-build slides and save them for instant recall during a show. Five templates:

  • Big Title — Large headline + optional subtitle. Good for segment openers.
  • Bulletin — Headline + bulleted list of lines. Announcements, housekeeping.
  • Next Event — Countdown-style card with label, event name, and date.
  • Spotlight — Photo + headline + subtitle. Individual recognition.
  • QR Code — Headline + body text + auto-generated QR from a URL.

Using Slides

  • Click + NEW SLIDE to start a blank slide in the editor on the right.
  • Pick a template, fill in the fields — the preview updates as you type.
  • Click 💾 SAVE to save it. It appears as a card on the left.
  • Click any card to load it back into the editor to update it.
  • Hit ▶ PUSH (on the card or in the editor) to send it to the projector immediately.
  • ✕ CLEAR DISPLAY blanks the projector screen.
Screen

VS Cards

Head-to-head matchup cards for the projector — a split-screen with each competitor's name, photo, and color. Fire one and the card slides in from both sides.

Themes

  • Arcade — Classic dark with colored namebars.
  • Fire vs Ice — Red/orange left side, blue right side.
  • Neon — Dark background with glowing neon text.
  • 8-Bit NES — Retro game aesthetic: purple-navy bg, cyan photo boxes, magenta "VS" text, Press Start 2P font.

Photos

Upload a photo for each side, or pick from the display library. The SIZE slider controls zoom — drag left to see the full image, right to fill the box.

Walk-Up

Each VS Card can have its own walk-up music and lighting. When you FIRE the card, the music starts and the walk-up scene fires automatically. Set the after-fade scene to what you want the lights to settle into.

Firing a VS Card

Click FIRE inside the card editor — or add a VS Card step to your Show Flow and fire it from the Operator console.

Screen

Game Entries

Participant records for games (Feud, Wheel, etc.). Each entry has a name, color, and optional logo — the same walk-up pipeline as Circles. The game engine pulls entries from this list when it needs participants.

Screen

Games

Saved configurations for each game type (wheel entries, trivia question sets, timer presets). Select a game type on the left, manage configs on the right. A Show Flow step can point to a specific saved config so it's pre-loaded at showtime.

Timer Presets

Set custom durations, warning times, and sound cues. Pick a preset when building a show flow step instead of entering numbers from scratch each time.

Musical Chairs

Pick a song (from the Library or imported from USB), set auto-stop on (random timing) or off (manual STOP only). STOP pauses the song in place — it resumes from there on the next START instead of restarting. An optional Intro Game Entry video, or — built right into the config, no separate slide to make — a headline/text/image screen (shown only if no Intro Game Entry is set), fires the instant you GO LIVE and stays up the whole game; START only ever affects the music. Also optional: skip the song's intro on the first play, a pulsing scene on start, and a stop-cue sound/scene. No contestant tracking — chairs and eliminations are handled physically.

Live

Music Viz

Controls what the crowd lighting does while music is playing. Two internal tabs:

Music Mode

Presets for live music visualization — VU Meter (bars that bounce with the beat), Radial (dots arranged in a ring), or a static scene. Each preset can specify a lighting scene to activate when that preset is selected.

Crowd Meter

Manual crowd energy control — an operator slider that drives lighting intensity. Set level effects for low/medium/high energy, and define what happens when the crowd hits peak (climax macro).

Show

Show Flow

The ordered rundown of your show. Each step is either a Macro, a VS Card, or a Game. The Operator console displays them as buttons in order, ready to fire one by one.

Building the Flow

  • Click + ADD STEP and pick the step type.
  • Give each step a display name and color — this is what appears on the Operator console.
  • Add optional notes visible to the operator (e.g., "Henry walks up, hold until applause dies").
  • Use ↑ ↓ to reorder. Click a step to edit it, then click UPDATE or CANCEL.
  • Click SAVE SHOW FLOW to persist.

Saved Flow Templates

At the bottom of the Show Flow tab: type a name and click 💾 SAVE CURRENT to save a snapshot of the current flow as a template. Later, click ⤓ LOAD to restore it — this replaces the active flow. Useful for saving a "Spring Camp" flow vs. a "Practice Run" flow.

Show

Macros

A macro is a sequence of actions that fire in order when triggered. Actions can include:

  • Play SFX — play a sound effect from the library
  • Set Lighting Scene — activate a named lighting preset
  • Walk-Up — trigger a circle or role walk-up
  • Fire VS Card — display a VS Card on the projector
  • Display Image / Slide — push a saved slide or image
  • Wait — pause for a set number of seconds before the next action

Macros are the workhorse of a show. Most show flow steps point to a macro — the macro handles the sequencing so the operator just taps once.

Tip: Build a "Climax" macro for crowd peak moments — strobe the poles, blast a sound, maybe fire a VS card — and hook it up to the Crowd Meter's climax trigger.
Settings

Lighting

Hardware configuration for the light fixtures. Set up once per venue/system, then leave it alone:

  • WLED IP — IP address of the WLED controller on the network
  • Pole Nodes — ESP32-based pole controllers, each with its own IP and DMX config
  • DMX Channels — pin-spot and wash fixture channel maps per pole
  • ↻ REBOOT — power-cycles a pole node's firmware remotely if it's acting up
  • ⇄ SYNC PRESETS — copies Pole A's saved WLED presets onto every other pole. WLED presets live on each device's own flash and aren't covered by the realtime strip sync, so run this after building/editing presets on Pole A
Settings

Lighting Scenes

Named presets that set a lighting state — a color, effect, or combination. Circles, Roles, VS Cards, and Macros all reference scenes by name. Change the scene definition here and every reference updates automatically.

  • Click a scene on the left to edit it, or + ADD SCENE for a new one.
  • Scenes can target WLED effects, a solid color, pole DMX states, or a combination.
  • Use descriptive names: "Campfire", "Blue Wash", "Strobe Poles", etc.
  • Multi-pole rigs: check OTHER POLES FOLLOW FIRST POLE in DMX Fixtures to mirror Pole A's look everywhere, or check OTHER POLES USE A DIFFERENT PRESET in WLED Preset to let each pole recall its own preset instead of a shared one.
Settings

Audio

Manage the on-Pi music and sound effect libraries. Upload files here; they're then available to pick in Circles, Roles, VS Cards, and Macros.

  • Music Library — walk-up tracks, background music. Any MP3/OGG/WAV.
  • SFX Library — short sound effects used in macros (stings, buzzers, chimes).

Files are stored on the Pi at /home/pi/musicman/assets/music/ and .../assets/sfx/.

Settings

Display

Manage images and videos available for slides, circles, roles, VS cards, and game entries. Upload here; then pick from the library anywhere a file slot appears.

  • Images: PNG, JPG, GIF, WebP
  • Videos: MP4, WebM (used for intro/loop animations)

📷 BAND Photo Slideshow — pulls photos from the group's BAND album and shows them full-screen with a floating QR code inviting attendees to add their own. One-time setup: register an app at developers.band.us, enter the Client ID/Secret here, hit Authorize, paste the code back, then Sync Now to pull photos down. Season mode shows every synced album; Event mode shows just one. Start/Stop Slideshow puts it on the projector — this is a manual trigger for now, not wired into Show Flow yet.

Settings

USB Import

Plug a USB stick into the Pi to import files without needing a laptop connected. Browse the USB contents here and copy files directly to the music or display libraries.

The stick is detected automatically — if you don't see files, try re-inserting it and hitting REFRESH.

Settings

System

Pi health at a glance — CPU temp, disk usage, uptime, and service status. Use this to check that everything is healthy before a show.

  • Service Controls — restart the Music Man service if something stops responding.
  • Disk Usage — keep an eye on this if you're importing lots of large video files.
  • Temperature — the Pi 4B runs warm; above 80°C means you need more airflow.

Common Workflows

Running a Show

  1. Make sure the Show Flow is saved with the right steps.
  2. Open the Operator console at http://musicman.local/ on an iPad or tablet.
  3. Steps appear as colored buttons in order — tap the current step to fire it.
  4. For walk-ups, the circle or role fires automatically if configured in the macro.
  5. Slides and VS cards fire to the projector automatically.
  6. Music fades out on its own after the configured duration.

Adding a New Circle Family

  1. Go to Walk-Ups → Circles, click + ADD CIRCLE.
  2. Enter the family name and pick their color.
  3. Upload a logo (or pick from the display library).
  4. Upload a walk-up track (or pick from the music library / USB stick).
  5. Set START to skip any silence in the track, DURATION for how long to play, FADE for the fade-out.
  6. Optionally add an Intro Clip (plays once) and Loop Clip (loops after intro).
  7. Set Walk-Up Scene and After-Fade Scene.
  8. Click SAVE CIRCLE.

Setting Up a VS Card Matchup

  1. Go to Screen → VS Cards, click + NEW CARD.
  2. Enter a card name (e.g., "Smith vs Jones").
  3. Fill in both sides: name, sub-label, color, and photo.
  4. Use the SIZE slider to control photo zoom — left = show full image, right = fill crop.
  5. Pick a theme: Arcade, Fire vs Ice, Neon, or 8-Bit NES.
  6. Under WALK-UP, assign music and a lighting scene that fires when the card is shown.
  7. Click SAVE, then FIRE to test it on the projector.

Building a Show Flow

  1. Go to Show → Show Flow.
  2. Click + ADD STEP for each segment of the show.
  3. Choose the step type: MACRO (most common), VS CARD, or GAME.
  4. Give each step a display name and color — this is what the operator sees on the console.
  5. Add any operator notes (shown below the button on the console).
  6. Reorder with ↑ ↓. Edit a step by clicking it.
  7. Click SAVE SHOW FLOW when done.
  8. Save a named template in the SAVED FLOWS card if you want to recall this flow later.
