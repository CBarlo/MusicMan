Standard WLED devices — string lights, crowd strips, uplights. These appear in Lighting Scenes so you can set color and effect per scene.

⚡ POLE NODES

ESP32 nodes on each pole. Define IP address and DMX fixtures. Scenes use these to set fixture channel values.

Locks each node to its configured IP by MAC address. Run after adding or changing nodes.
